## ⚡ 60-Second Setup: Activate Live on GitHub Pages

You can publish this storefront completely free in under 60 seconds.

### Method 1: In Your Browser (Zero Terminal Required — Easiest)

1. **Create Repository:**
   - Go to [GitHub.com/new](https://github.com/new).
   - Repository Name: `mia-finds` (or `miaviralfinds.github.io` for a root domain).
   - Set to **Public**.
   - Do **NOT** check "Add a README file" (we already have one).
   - Click **Create repository**.

2. **Upload Files:**
   - On the new repository page, click **uploading an existing file**.
   - Drag and drop all files from this `mia_storefront_gh_pages/` folder:
     - `index.html`
     - `avatar.jpg`
     - `.nojekyll`
     - `README.md`
   - Click **Commit changes**.

3. **Enable GitHub Pages:**
   - In your repo, click **Settings** (top tab) ➔ **Pages** (left sidebar under "Code and automation").
   - Under **Build and deployment** ➔ **Source**, select **Deploy from a branch**.
   - Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
   - Click **Save**.

4. **Done!**
   - In 15–30 seconds, refresh the Pages tab. Your live URL will appear:
   - **`https://<your-github-username>.github.io/mia-finds/`** (or `https://antonavanozian.github.io/miaviralfinds/`)

### Method 2: Via Git Command Line (Power Users)

Run these commands inside this folder:

```bash
git init
git add .
git commit -m "feat: launch Mia Viral Finds official link-in-bio storefront"
git branch -M main
git remote add origin https://github.com/<your-github-username>/mia-finds.git
git push -u origin main
```
Then go to **Repo Settings ➔ Pages ➔ Source: Deploy from branch `main` / `root` ➔ Save**.
